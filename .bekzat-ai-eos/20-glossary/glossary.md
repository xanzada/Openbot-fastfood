# Glossary — Терминдер сөздігі

> Нұсқа: 1.0
> Статус: Active

---

## A

| Термин | Сипаттамасы |
|--------|-------------|
| **ADR** | Architecture Decision Record — маңызды архитектуралық шешімнің құжаттамасы |
| **Agent** | VoltAgent — LLM-мен жұмыс істейтін AI агент |
| **api_bot.php** | DLE-дегі PHP шлюз, Node.js бот пен DLE/MySQL арасындағы байланыс |
| **Async fire-and-forget** | Жауап күтпейтін асинхронды операция (мысалы: shpor eval) |

## B

| Термин | Сипаттамасы |
|--------|-------------|
| **Backup cache** | Негізгі көз қолжетімсіз болғанда қолданылатын stale cache |

## C

| Термин | Сипаттамасы |
|--------|-------------|
| **Chatwoot** | Customer support платформасы (опционалды) |
| **Chief Architect** | Жүйенің техникалық тұтастығын, масштабталуын және сапасын қамтамасыз ететін рөл |
| **Circuit breaker** | Сыртқы жүйе сәтсіздік кезінде қайталанатын сұрауларды блоктайтын паттерн |
| **Code Review** | Код сапасын, қауіпсіздікті және консистенттілікті қамтамасыз ететін процесс |
| **Conventional Commits** | feat:, fix:, refactor:, docs:, test:, chore: типті commit conventions |
| **CRM** | Customer Relationship Management — клиенттер базасы (DLE-де) |
| **Cron** | Күнделікті аналитика есебін жіберетін scheduler |

## D

| Термин | Сипаттамасы |
|--------|-------------|
| **DAG** | Directed Acyclic Graph — бағытталған циклсіз граф (dependency graph) |
| **DLE** | DataLife Engine — ресторанның CMS-і |
| **DNS Safety** | SSRF қорғаныс — private IP-ге DNS lookup блоктау |
| **Domain** | Әрбір ресторанның DLE сайтының домені |

## E

| Термин | Сипаттамасы |
|--------|-------------|
| **EOS** | Engineering Operating System — инженерлік жүйе |
| **Engineering Constitution** | Инженерлік ұжымның жұмыс принциптері мен міндетті ережелерінің жиынтығы |
| **Escalation** | Мәселені админге/операторға көтеру |
| **evaluateForShpor** | GPT-4o-mini арқылы диалогты "екінші миға" сақтау керек пе екенін анықтау |

## F

| Термин | Сипаттамасы |
|--------|-------------|
| **FACTS_CONTEXT** | LLM-ге берілетін JSON форматындағы фактілер |
| **finalValidator** | LLM шығарған жауапты постыңғы өңдейтін код (2 сөйлем, тіл тазалығы, т.б.) |
| **fromMe** | Оператордың өзі жазған хабарлама (бот оны өңдемейді, mute қояды) |

## G

| Термин | Сипаттамасы |
|--------|-------------|
| **Guard** | Кіріс хабарламаларды фильтрлейтін қабат (spam, duplicate, mute) |
| **Gateway** | Eski жүйе — ағымдағы openbot-agent оны ауыстырды |

## H

| Термин | Сипаттамасы |
|--------|-------------|
| **Hallucination defense** | 4 деңгейлі қорғаныс: instructions → pre-LLM → validator → facts |

## L

| Термин | Сипаттамасы |
|--------|-------------|

## M

| Термин | Сипаттамасы |

| Термин | Сипаттамасы |

| Термин | Сипаттамасы |
|--------|-------------|

## S

| Термин | Сипаттамасы |
|--------|-------------|
