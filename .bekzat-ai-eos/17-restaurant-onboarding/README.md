# 17. Restaurant Onboarding

> Мақсаты: Жаңа ресторанды жүйеге қосу процесін құжаттау.

## Онбординг процесі

```
1. Контакт жинау → 2. Мәзір жүктеу → 3. NocoDB конфигурация → 4. WhatsApp тест → 5. Іске қосу
```

## Қадамдар

### 1. Контакт жинау

- Ресторан атауы
- WhatsApp нөмірі
- Мекен-жайы
- Жұмыс уақыты

### 2. Мәзір жүктеу

- NocoDB-ге мәзірді импорттау
- Категориялар
- Бағалар
- Сипаттамалар

### 3. NocoDB конфигурация

- Жаңа tenant жолы: `config` таблицасына жазба
- Token генерация
- Webhook URL конфигурация

### 4. WhatsApp тест

- Тест хабарламасын жіберу
- Мәзір сұрау
- Заказ тест

### 5. Іске қосу

- Ресторанға хабарлау
- Мониторинг қосу
- Онбординг чек-листін жабу
