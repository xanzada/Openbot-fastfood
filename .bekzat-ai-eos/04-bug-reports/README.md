# 04. Bug Reports

> Мақсаты: Барлық багтар мен регрессияларды бірыңғай форматта тіркеу.

## Ережелер

1. Әрбір багка бірегей BUG-NNN нөмірі беріледі
2. Багтың статусы: New → Confirmed → In Progress → Fixed → Verified → Closed
3. Critical/P1 багтар 1 сағат ішінде қаралуы керек
4. Регрессия анықталса, дәл сол тестпен automated test жазылады

## Bug Severity

| Level | Анықтама | Жауап беру уақыты |
|-------|----------|-------------------|
| **P0-Critical** | Жүйе жұмыс істемейді, деректер жоғалады | 1 сағат |
| **P1-High** | Негізгі функционал бұзылған, workaround жоқ | 4 сағат |
| **P2-Medium** | Функционал жұмыс істейді, бірақ қате бар | 24 сағат |
| **P3-Low** | Косметикалық өзгерістер, UX жақсартулар | 1 апта |
