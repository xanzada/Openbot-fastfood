# 05. Feature Design

> Мақсаты: Жаңа мүмкіндіктердің дизайнын толық құжаттау, бекіту және жүзеге асыруды бақылау.

## Ережелер

1. Әрбір жаңа мүмкіндік feature design документінен басталады
2. Кем дегенде 2 балама шешім ұсынылуы керек
3. Business logic prompt-та емес, кодта болады
4. Privacy/Security review міндетті (егер деректерге қатысты болса)
5. Feature толық іске асырылған соң документ жабылады

## Feature Lifecycle

```
Idea → Draft → Review → Approved → In Development → Testing → Released → Retrospective
```
