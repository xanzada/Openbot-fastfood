# Feature Request: WhatsApp-тан заказды DLE-ге жіберу

> **Submitted by:** Ресторан операторы
> **Date:** 2026-06-15
> **Priority:** High

---

## Сипаттамасы

Клиент WhatsApp арқылы заказ бергенде (мысалы, "1 үлкен Маргарита, 1 Кола"), бот бұл заказды автоматты түрде DLE API арқылы ресторанның тапсырыс жүйесіне жіберуі керек. Қазір бот тек ақпарат береді, заказды қабылдамайды.

## Business Value

- Клиенттерге WhatsApp арқылы заказ беруге мүмкіндік береді (35% клиенттер телефонмен емес, мессенджермен заказ бергісі келеді)
- Операторлардың жұмысын жеңілдетеді (заказды қолмен енгізудің қажеті жоқ)
- Адам факторын азайтады (қате заказ, дұрыс емес баға)
- Тапсырыс көлемін 15-20% арттыру потенциалы

## User Impact

- **Кім пайдаланады?** Ресторан операторлары және клиенттер
- **Қанша пайдаланушыға әсер етеді?** 10+ ресторан, күніне 50-200 заказ
- **Қаншалықты маңызды?** High — бұл ең көп сұралатын функция

## Workaround (егер бар болса)

Қазір клиенттер WhatsApp арқылы "заказ бергім келеді" деп жазады, бот оларға телефон нөмірін береді. Клиенттер қоңырау шалып немесе қолмен заказ береді. Бұл — friction point.

## Acceptance Criteria

- [ ] 1. Клиент "1 Маргарита, 2 Кола" деп жазса, бот заказды DLE-ге жібереді
- [ ] 2. DLE API жауап қайтарса (success/fail), бот клиентке хабарлайды
- [ ] 3. Заказ форматы: { items: [{name, quantity, price}], phone, total }
- [ ] 4. DLE API 5s ішінде жауап бермесе → клиентке "Заказ қабылданды, оператор хабарласады" деп айту
- [ ] 5. Егер DLE API fails болса → клиентке "Кейінірек хабарласыңыз" + операторға хабарлама
