# Examples

## Жалпы

Бұл директория әртүрлі сценарийлер бойынша request/response мысалдары үшін.

## Мысал сценарийлер

### 1. Мәзір туралы сұрау
```
Клиент: "Маған мәзір керек еді"
Жауап: "Мәзірімізбен танысу үшін сілтемені жіберемін."
(жеке хабарлама: URL)
```

### 2. Асхана статусы
```
Клиент: "Қазір тамақ алуға бола ма?"
Жауап: "Иә, асхана ашық. Күту уақыты 15-20 минут."
```

### 3. Төлем чек
```
Клиент: (чек суреті)
Жауап: "Чекіңіз тіркелді. Рақмет!"
```

### 4. Эскалация
```
Клиент: "Тапсырысым жоғалды"
Жауап: "Өкінішті, бұл мәселені шешу үшін сізді әкімшіге қосамын."
(админге хабарлама)
```

### JSON request/body мысалдары
- Full webhook body
- NocoDB config response
- DLE runtime status
- Redis key format
